# Repository Guidelines

This repository contains the homelab knowledge vault under `vault/`.

**If you are making changes to the content of the vault** (anything under `vault/` — notes, logs, todos, container notes, or `vault/AGENTS.md` itself), read and follow **`vault/AGENTS.md`**. It is the authoritative source for the vault's conventions: formatting, front matter, linking, commit message style, and change documentation.
