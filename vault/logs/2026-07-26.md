# 26/07/2026

## Vault Consistency Sync (Cron Job)

Created a daily cron job at `job_id: a44601cc0e9d` that checks the vault for new commits, syncs log/todo work into container notes, and verifies linking conventions.

### How it works

**Detection script** (`~/.hermes/scripts/hermes-vault-diff-check.py`):

- `no_agent` mode — zero LLM tokens, runs every tick
- Tracks last checked commit in `~/.hermes/scripts/.hermes-vault-diff-state.json`
- Fetches from GitHub, pulls, compares HEAD against last known commit
- Silent (no output) when nothing has changed — cron delivers nothing
- On new commits: outputs the commit range + changed files list as agent context

**Agent job** (runs at 08:00 daily):

- Loads the `homelab-vault-notes` skill for conventions
- Receives the detection script's output as context
- If new commits exist:
  1. Reads changed `logs/` files for new container-relevant sections
  2. Reads changed `todo/` files for newly completed items
  3. Syncs work summaries into the corresponding `containers/` notes
  4. Verifies linking conventions per AGENTS.md
  5. Runs markdownlint, commits, and pushes
  6. Delivers a concise summary
- If no changes: reports nothing, no tokens spent

**Container note update pattern:**

- New work found in logs or todos gets added as a dated entry under `## Changes` (or creates the section if it doesn't exist)
- Skips services without a `containers/` note
