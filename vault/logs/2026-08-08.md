# 08/08/2026

## Home Assistant — Tuya Lamp

- Wi-Fi Tuya lamp turned on via Home Assistant, but the dashboard state did not update, so it could not be turned off from the dashboard
- Cause: the continuous cloud data pipeline between Tuya and Home Assistant had crashed — Home Assistant could still send one-way commands ("turn on"), but Tuya could not send back the "I am turned on" status confirmation
- Fix: reloaded the Tuya integration (Settings > Devices & Services > Tuya > ⋮ > Reload), which reset the connection and restored normal control
- Lesson: Tuya cloud streams can be unstable. If the dashboard stops reflecting Tuya device state while commands still work one-way, reload the Tuya integration rather than removing and re-adding the device.
