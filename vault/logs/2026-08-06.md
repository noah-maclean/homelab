# 06/08/2026

## OpenWhispr — local dictation app (Mac)

Installed **OpenWhispr** on the daily-driver Mac (2026-08-06) — an open-source (MIT), cross-platform (macOS/Windows/Linux) Electron app: effectively a free, privacy-first WisprFlow alternative. Website: openwhispr.com · repo: github.com/OpenWhispr/openwhispr.

- **Local engines** — `whisper.cpp` (Whisper tiny/base/small/medium/large + turbo, GGML, Metal-accelerated on Apple Silicon) and `sherpa-onnx` for NVIDIA **Parakeet** / **Nemotron** (~630–680 MB models, faster on laptops, streaming variants available).
- **Cloud BYOK providers** — OpenAI, Groq (whisper-large-v3-turbo), xAI (Grok STT), Mistral, Tinfoil, Corti, OpenRouter, Anthropic/Gemini; plus OpenWhispr Cloud free tier (2,000 words per rolling 7 days).
- **Per-mode engine selection** — Dictation / Note Recording / Audio Upload each keep their own engine choice (Settings → Speech-to-Text).

Decisions:

- Primary local model: **whisper large-v3-turbo** (~1.6 GB) — near-large accuracy (≈2.5% WER) at ~8× speed, comfortable on Apple Silicon.
- **Parakeet** (`parakeet-tdt-0.6b-v3`) kept as the speed-focused alternative for dictation.
- **Groq key deliberately not connected** — preference to keep all dictation audio on-device. Note: Groq ≠ Grok — Groq serves OpenAI's open Whisper weights, so cloud vs local turbo is the *same model*; zero accuracy difference, only speed/battery/privacy trade-offs. The Groq key can be added later as a complement for instant dictation without changing quality (same weights [[hermes_agent|Hermes]] already uses for Discord voice notes).

## Hermes — Telegram channel removed

Removed the [[hermes_agent|Hermes]] Telegram gateway channel (2026-08-06) — the platform was unused (Discord is the only messaging platform in active use). No cron jobs or other features delivered to Telegram (verified in `~/.hermes/cron/jobs.json`), so nothing depended on it.

- `~/.hermes/.env` — commented out `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_USERS`, `TELEGRAM_HOME_CHANNEL` (backup: `~/.hermes/.env.bak-telegram-20260806`; token intact, reversible).
- `~/.hermes/config.yaml` — removed the `telegram:` section with `hermes config unset telegram`.
- Gateway **not** restarted during the change (restart is blocked from inside the gateway process). The running process still holds the Telegram bot connection until the next `hermes-gateway.service` restart, after which it drops permanently.
