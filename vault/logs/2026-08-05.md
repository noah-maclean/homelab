# 05/08/2026

## [[hermes_agent|Hermes]] — Discord voice latency tuning

First Discord voice test with Noah. Two findings:

- **Latency was mostly STT-bound.** `stt.provider` is `local` (faster-whisper) on the 2-core LXC. Changed `stt.local.model` from `base` → `tiny` via `hermes config set stt.local.model tiny` to cut transcription time ~2-3x. Takes effect after gateway restart (`/restart` in Discord or `systemctl --user restart hermes-gateway`).
- **Groq STT is the next step** for <1s transcription (free tier, whisper-large-v3-turbo). Needs a `GROQ_API_KEY` in `~/.hermes/.env` + `hermes config set stt.provider groq`. Noah to grab key from console.groq.com when ready.

Voice layout decision: use a **dedicated text channel** for voice conversations rather than threads (threads auto-archive after 3 days). Bot lacked `MANAGE_CHANNELS`, so Noah will create `#voice` under the Voice channels category manually.
